# 暗雲寶箱（FF14 暗之雲〈滅〉通關開箱 Roll 點）

FF14 7.1「暗之雲（滅）」打完後的開箱場地：開房間、把邀請連結傳給隊友，大家一起走近寶箱開箱，
用「需要／貪婪／放棄」比點數分裝備。原創的 FF14 風格介面，不使用官方素材。

**線上版**：https://azusa0312.github.io/clouddark-loot/

## 怎麼玩

1. 打開網頁，輸入你的 ID（顯示在角色頭上）、選職業，按「建立房間」。
2. 右上角按「複製邀請連結」，傳給隊友。隊友打開連結、輸入 ID 和職業就會進到同一個房間（最多 8 人）。
3. 走近北邊的寶箱就會打開，全房間同時跳出戰利品清單。
4. 每件物品選 **需要／貪婪／放棄**：當場擲 1～99。需要優先於貪婪，同一層級點數大的得到；全部放棄就沒人拿。
   倒數結束沒選的人自動放棄。所有人都能選需要，拿過的東西也能再 roll。
5. 房主按「再放一箱」開下一箱。

**操作**：WASD 移動、空白鍵跳躍、拖曳轉視角、滾輪縮放、Enter 聊天（再按 Enter 送出、Esc 取消）。
聊天輸入 `/random` 擲 1～999 給全房間看。

## 掉落

- 每箱固定 2 件不重複的裝備箱（暗雲 頭部／身體／手部／腿部／腳部）。
- 稀有物品：暗黑領域（坐騎）、暗黑羽衣（坐騎）、薄暗之雲（寵物）、髮型樣式：半雙馬尾。
- 房主可以在「掉落設定」調整：
  - 機率模式：每件稀有物品各自 15%（可改）
  - 必出模式：每箱固定出 1～4 件稀有物品
  - 擲骰倒數秒數
- 機率為自訂數字，**非官方數據**（官方沒有公布掉落率）。

## 紀錄

- **紀錄**：房間裡每個人拿到哪些物品、各幾件，以及每件物品的擲骰歷史。存在房主那邊，房主關掉網頁就清空。
- **我的收藏**：自己拿到過的物品，存在自己的瀏覽器裡，換房間也會保留。

## 連線方式

- 瀏覽器之間直接連線（WebRTC），透過 PeerJS 的公開服務配對，不用架伺服器、不用註冊。
- 所有隨機結果（開箱內容、擲骰、/random）都由房主的瀏覽器決定再廣播，大家看到的結果一致，也沒辦法改自己的點數。
- 房主要一直開著網頁，房主關掉房間就解散。
- 有人斷線約 9 秒內會被移出房間，正在 roll 的物品不會卡住。
- 連不上連線服務時會自動改成單人模式（可以自己開箱測試）。

## 檔案結構

```
index.html          畫面骨架（進房、HUD、戰利品、紀錄、收藏、設定）
css/style.css
three.min.js        Three.js r152
peerjs.min.js       PeerJS 1.5.4
js/boot.js          依序載入（本機檔案優先，失敗改用 CDN）
js/config.js        設定檔：人數、隊伍數、掉落表、機率、職業
js/net.js           傳輸層（PeerJS；房主／成員／單機、心跳）
js/room.js          房間狀態與規則（房主判定：加入、開箱、擲骰、聊天、/random）
js/scene.js         3D 場地、寶箱、角色（頭上 ID＋職業）
js/main.js          進房、移動、跳躍、相機、戰利品、紀錄、收藏、設定、聊天
```

之後要擴充成 3 隊 24 人：把 `js/config.js` 的 `TEAM_COUNT` 改成 3。每隊會有自己的寶箱，只能 roll 自己隊的箱子。
